# CY Writing — 池一诺综合创意写作作品集

为「about关于」综合创意写作岗位整理的个人作品网站。

## 页面结构

1. **自我介绍**：教育背景、内容经历与创作工具
2. **个人写作**
   - 「东71街日记」：11 篇微信公众号文章
   - 「0.66摩」：3 篇小红书笔记

网站采用千禧年电脑桌面风格，以蓝色文件管理器呈现公众号写作，以粉紫色媒体播放器呈现小红书内容。
